# OSINT Panel

Веб-панель для агрегации **публичной** OSINT-информации из открытых источников: WHOIS доменов, геолокация IP-адресов, базовая проверка email и SSL-сертификатов.

⚠️ **Область применения.** Инструмент работает только с общедоступными техническими данными (домены, IP, DNS, сертификаты). Он не предназначен и не должен использоваться для поиска по слитым базам данных, деанонимизации людей, сбора персональных данных без согласия или иных действий, нарушающих законодательство о персональных данных и приватности.

## Возможности

- **WHOIS** — регистратор, даты создания/истечения домена, NS-серверы, статус
- **IP Geolocation** — страна, город, провайдер по публичному API (ipinfo.io)
- **Email check** — валидация формата и проверка MX-записей домена
- **SSL info** — издатель, срок действия и SAN сертификата сайта

## Desktop UI (.exe)

Помимо запуска через браузер, доступна готовая desktop-сборка панели для Windows:

📥 [`dist/osint-panel-ui.exe`](./dist/osint-panel-ui.exe)

Скачайте файл и запустите — приложение поднимет локальный сервер и откроет интерфейс панели в отдельном окне, без необходимости вручную запускать `python run.py` и открывать браузер.

> На данный момент в `dist/` находится заглушка — файл будет заменён на актуальную сборку.

## Установка

```bash
git clone <repo-url>
cd osint-panel
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env` при необходимости (токен ipinfo.io для более высокого лимита запросов).

## Запуск

```bash
python run.py
```

Панель будет доступна на `http://localhost:5000`.

## API

Все эндпоинты принимают `POST` с JSON-телом и возвращают JSON.

| Эндпоинт      | Параметр   | Описание                          |
|---------------|------------|------------------------------------|
| `/api/whois`  | `domain`   | WHOIS-данные домена                |
| `/api/ip`     | `ip`       | Геолокация IP-адреса               |
| `/api/email`  | `email`    | Проверка формата и MX-записей      |
| `/api/ssl`    | `hostname` | Информация о SSL-сертификате       |

Пример запроса:

```bash
curl -X POST http://localhost:5000/api/whois \
  -H "Content-Type: application/json" \
  -d '{"domain": "example.com"}'
```

## Расширение

Чтобы добавить новый модуль:

1. Создайте файл в `app/modules/`, реализующий функцию, возвращающую `dict`
2. Добавьте маршрут в `app/routes.py`
3. Добавьте карточку в `app/templates/index.html` и вызов в `app/static/app.js`

Планы по расширению: интеграция Shodan (баннеры сервисов по IP), проверка утечек через публичные agregate-сервисы с прозрачным consent-флоу, экспорт отчётов в PDF/CSV.
